# Симулятор спроса — Контур

Интерактивный симулятор авиационного спроса: обращения клиентов, покупки, отмены, вместимость салонов, тарифы и оценка скрытого спроса. Интерфейс на русском языке. Расчёты и импорт CSV выполняются в браузере.

![Интерфейс симулятора](docs/preview.png)

## Скачать и запустить

1. На странице репозитория нажмите зелёную кнопку **Code → Download ZIP**. Для закрытого репозитория сначала войдите в аккаунт GitHub, которому предоставлен доступ.
2. Распакуйте скачанный ZIP в отдельную папку.
3. Установите [Node.js](https://nodejs.org/) версии 22 или новее, если он ещё не установлен.
4. **Windows:** дважды нажмите `START-WINDOWS.cmd`. **macOS / Linux:** откройте терминал в распакованной папке и выполните `node server.mjs`.
5. Откройте в браузере **http://127.0.0.1:4173**.

Оставьте окно сервера открытым, пока пользуетесь приложением. Чтобы остановить его, нажмите `Ctrl+C` в этом окне. Установка npm-пакетов для запуска не нужна. Если порт 4173 занят, завершите предыдущий запуск симулятора.

Альтернативный запуск из терминала: `npm start`. Проверка расчётной модели: `npm test`.

## Как пользоваться

- Слева настройте первичный спрос, количество мест, дату вылета, стартовый тариф, бюджет клиентов, профиль обращений и вероятность отмены. Графики пересчитываются автоматически.
- Один **seed** сохраняет тот же набор обращений при смене тарифа или вместимости. Кнопка рядом с seed создаёт новый случайный сценарий.
- Нажмите **«Сравнить сценарии»**, чтобы сохранить текущий расчёт как базу. Затем меняйте параметры: появятся разницы в балансе мест, покупках, скрытом спросе и выручке. Кнопка **«Убрать»** удаляет базу.
- Переключатель **«Оценка»** сравнивает распределение скрытого спроса по методу ноутбука с фактическими отказами синтетического сценария.
- В журнале событий можно выбрать результат операции и passenger-подобную реконструкцию.
- Меню **«Экспорт»** скачивает журнал bookings, реконструкцию, все события или JSON параметров.

Стартовые данные синтетические. Исходные CSV реальных рейсов не включены. Для знакомства с импортом в папке `examples/` есть синтетический журнал `bookings-SU1122-2027-05-22.csv`: спрос 300 мест, дата вылета 2027-05-22.

## Импорт bookings CSV

Нажмите **«Загрузить CSV»** и выберите один или несколько файлов. Обязательные столбцы:

```csv
timestamp;cabin;rbd;commercial;price
2027-05-01T12:00:00Z;Y;R;2;12000
2027-05-02T12:00:00Z;Y;R;-1;12000
```

- `commercial > 0` — покупка; `commercial < 0` — отмена. Значение должно быть ненулевым целым числом.
- Число мест — модуль `commercial`, цена — за одно место.
- Необязательный столбец `flight` задаёт рейс. Если его нет, рейс определяется из имени файла вида `bookings-SU1122-2027-05-22.csv`.
- Перед загрузкой задайте дату вылета и известный первичный спрос. Спрос относится к **каждому** рейсу отдельно и не может быть меньше суммы мест во всех покупках до отмен.
- Поддерживаются разделители `;`, запятая и табуляция, UTF-8 и BOM. Время без часового пояса считается UTC. Общий размер файлов ограничен 10 МБ.

Файлы обрабатываются локально в браузере и не отправляются на сервер. Сохранённая база сравнения содержит параметры и агрегаты в localStorage этого браузера.

## Методология

Приложение построено на основе ноутбука `passengers_reconstruction_from_bookings.ipynb`. Сохранены следующие правила:

```text
Спрос без покупки = первичный спрос − все купленные места до отмен
Баланс мест       = купленные места − отменённые места
Чистая выручка    = сумма(commercial × price)
```

Отменённое место уже участвовало в первоначальной покупке и не прибавляется к спросу без покупки. Скрытые места распределяются по периодам `91+`, `31–90`, `15–30`, `8–14`, `0–7` пропорционально покупкам, с целочисленным распределением методом наибольших остатков.

В реконструкции `amount` остаётся пустым, ID являются техническими. Для оценённого скрытого спроса создаются агрегаты по периодам без выдуманных времени, салона, RBD, цены или бюджета.

Генератор сценариев добавлен отдельно: группы клиентов, логнормальный бюджет (σ = 0,48), динамический тариф, отдельные ограничения мест в салонах, полные отмены групп с возвратом денег. Это явные сценарные допущения, а не параметры, восстановленные из bookings. Подробности доступны в **«О модели»**. Распределение скрытого спроса по периодам остаётся грубой оценкой.

Для отображения шрифта приложение может обращаться к Google Fonts; при недоступности используется системный шрифт.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `dist/index.html`, `dist/styles.css` | Интерфейс и оформление |
| `dist/app.mjs` | Управление интерфейсом, графики, импорт и экспорт |
| `dist/model.mjs` | Расчётная модель и обработка CSV |
| `server.mjs` | Локальный статический сервер на 127.0.0.1:4173 |
| `tests/model.test.mjs` | Проверки расчётной модели |
| `examples/` | Синтетический пример bookings |
| `START-WINDOWS.cmd` | Запуск на Windows |
